# 🐍 Python 核心语法到大模型 RAG 应用开发实战笔记

本仓库为个人 Python 全栈与大模型 AI 应用开发的**全套学习笔记与实战代码**，涵盖从基础语法、面向对象高级、FastAPI 后端开发，到 LangChain RAG 知识库与 Agent 智能体构建的全过程。

---

## 📁 课程学习目录大纲

### 📚 1. 黑马程序员 - Python 与 AI 基础 (`01_黑马程序员_Python+AI基础/`)
- **`02_核心语法/`**：流程控制、数据容器（列表/字典/元组/集合）、函数开发与异常处理
- **`04_面向对象高级/`**：封装、继承、多态、鸭子类型，以及**图书管理系统**综合实战
- **`05_Web应用/`**：FastAPI Web 框架入门、静态资源部署与 RESTful 接口开发

### 🚀 2. Datawhale - 动手学大模型应用开发 (`02_Datawhale_动手学大模型开发/`)
- **`02_第二章_Prompt工程/`**：Prompt 编写原则、分隔符防注入、结构化 JSON 输出、少样本提示 (Few-Shot)
- **`03_第三章_搭建知识库/`**：PDF/Markdown 多源文档加载、正则数据清洗、`RecursiveCharacterTextSplitter` 文本切片、智谱 Embedding 适配器与 Chroma 向量数据库持久化
- **`04_第四章_构建RAG应用/`**：LCEL 表达式语言、`RunnableBranch` 多轮对话重写、检索问答链构建与 Streamlit 部署
- **`05_第五章_系统评估与优化/`**：BLEU 答案相似度评估、大模型自动打分 (LLM-as-a-Judge)、思维链 (CoT) 与反思优化
- **`06_案例二_人情世故大模型/`**：基于天机（Tianji）开源项目的 Word/TXT 预处理、自定义 LLM 继承与高情商知识库问答

---

## 🛠️ 技术栈与工具
- **编程语言**：Python 3.10+
- **Web / API 框架**：FastAPI, Streamlit
- **大模型 API**：DeepSeek API (`deepseek-v4-pro`), 智谱 AI (`embedding-3`)
- **大模型框架与数据库**：LangChain, Chroma DB
- **版本控制与部署**：Git, GitHub, Streamlit Community Cloud
