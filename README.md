# 🐍 Python 核心语法与项目实战笔记

本仓库用于记录“黑马程序员 Python+AI”课程的学习过程、基础语法练习与核心案例。

---

## 📁 课程学习大纲目录

### 1. 核心语法与面向对象基础
- **`02_核心语法/`**
  - **流程控制**：九九乘法表、随机数、循环案例
  - **数据容器**：列表 (List)、字符串 (Str)、元组 (Tuple)、集合 (Set) 综合练习
  - **函数开发**：函数定义、参数传递与高阶函数
  - **面向对象 (OOP)**：类与对象、魔法方法、教务系统与购物车系统实战
  - **异常处理**：`try-except` 机制与异常传递

### 2. AI 应用与进阶开发
- **`03_AI应用/`**
  - **大模型调用**：DeepSeek API 基础调用测试
  - **交互式 Web 开发**：Streamlit 框架快速入门与组件使用
  - **文件与持久化**：JSON 格式序列化与本地文件 I/O 读写
  - **多会话存储**：基于时间戳的会话保存与恢复逻辑
